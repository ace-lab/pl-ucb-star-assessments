Transactions analysis plan

Consider a transactions dataset with the following columns:

ColumnDescription
transaction_ida unique identifier for each transaction
customer_idan identifier for the customer associated with the transaction
store_idan identifier for the store where the transaction occurred
datethe date of the transaction
yearthe year of the transaction
totalthe total dollar amount of the transaction

Each row of the dataset represents one transaction.

Note: Customers can make more than one transaction at more than one store on a particular day.

Write an analysis plan for the question below.

  • Your analysis plan should start with the dataset above and result in a table that answers the question.
  • Your final table must only include rows that are relevant to the question. No extra rows.
  • Your final table may optionally include columns that are not required to answer the question. For example, if you are asked to identify customers, but your answer contains a transaction ID column that is not used, that's fine.
  • Your final table should require no additional computation to fully answer the question. A non-technical person should be able to answer the question by scrolling through your final table.

Use canonical English for every operation. Use the applicable operation phrases:

  • select or select distinct
  • filter rows where or filter for
  • group rows by or for each unique
  • join with both table names and matching columns for a multi-table question
  • compute count of, compute count distinct of, compute sum of, compute average of, compute minimum of, or compute maximum of; sum their is also accepted for a sum
  • keep groups where or aggregate the result with
  • order by with ascending or descending
  • keep the first or skip the first

Name every table and column exactly as shown above. Include all comparison operators, values, calculation inputs, and sort directions needed by your steps. Code-like shorthand such as df[...], groupby, or more_than is not accepted as canonical English.
