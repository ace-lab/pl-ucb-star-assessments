Cook County property sales: top neighborhoods

The table cook_county contains a deterministic sample of property sales from the Cook County training data used in DATA 100. Each row describes one sale record.

ColumnMeaning
property_idCook County parcel identifier
property_classassessor property-class code
neighborhood_codeassessor neighborhood code
building_sqftbuilding area in square feet
sale_pricerecorded sale price in dollars
modeling_groupSF, MF, or NCHARS
sale_yearyear of sale
garage_indicator1 when a garage is present
central_air1 when central air is present

For every sale year from 2016 through 2019, identify the three qualifying neighborhoods with the greatest mean sale price per building square foot.

A sale qualifies only when:

  • modeling_group = 'SF';
  • sale_price >= 10000 and building_sqft > 0; and
    • {{#params.garage_variant}}
  • garage_indicator = 1.
    • {{/params.garage_variant}} {{#params.central_air_variant}}
  • central_air = 1.
    • {{/params.central_air_variant}}

For each qualifying sale, first calculate sale_price * 1.0 / building_sqft. Then group by sale_year and neighborhood_code. Exclude a group if it has fewer than 10 qualifying sales. For every remaining group, report the qualifying sale count and the mean of the row-level price-per-square-foot values, rounded to two decimal places.

Rank neighborhoods separately within each year by the rounded mean in descending order. Break ties by neighborhood_code in ascending order. Return ranks 1 through 3.

Your result must contain exactly these five values for each returned row:

  1. sale_year
  2. neighborhood_code
  3. sale_count
  4. avg_price_per_sqft
  5. rank_in_year

Write one SQLite query that produces this result. You may use common table expressions and window functions. Result row order is not graded.
