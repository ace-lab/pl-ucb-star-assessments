Cook County property sales SQL query

Consider a cook_county dataset with the following columns:

ColumnDescription
property_ida Cook County parcel identifier
property_classthe assessor's property-class code
neighborhood_codethe assessor's neighborhood code
building_sqftthe building area in square feet
sale_pricethe recorded sale price in dollars
modeling_groupthe modeling category: SF, MF, or NCHARS
sale_yearthe year of the sale
garage_indicator1 when a garage is present and 0 otherwise
central_air1 when central air is present and 0 otherwise

Each row represents one single-family property sale. The dataset contains sales from 2013 through 2019.

Note: A property class or neighborhood may appear in many rows.
{{#params.task_a}}

(a) Property classes with large garage-equipped homes

How many property_class values have at least 30 sales with a garage and an average building_sqft greater than 2,500?

Return a one-row table with one column named property_class_count.

(b) High-value central-air neighborhoods

How many neighborhood_code values have at least 30 sales with central air and a combined sale_price greater than $200,000,000?
