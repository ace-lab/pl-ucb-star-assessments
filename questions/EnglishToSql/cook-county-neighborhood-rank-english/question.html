Cook County property sales analysis plan

Consider a cook_county dataset with the following columns:

ColumnDescription
property_ida Cook County parcel identifier
property_classthe assessor's property-class code
neighborhood_codethe assessor's neighborhood code
building_sqftthe building area in square feet
sale_pricethe recorded sale price in dollars
modeling_groupthe modeling category: SF, MF, or NCHARS
sale_yearthe year of the sale
garage_indicator1 when a garage is present and 0 otherwise
central_air1 when central air is present and 0 otherwise

Each row represents one single-family property sale. The dataset contains sales from 2013 through 2019.

Note: A property class or neighborhood may appear in many rows.

Write an analysis plan for the question below.

  • Your analysis plan should start with the dataset above and result in a table that answers the question.
  • Your final table must only include rows that are relevant to the question. No extra rows.
  • Your final table should require no additional computation to fully answer the question.
  • You may name an intermediate result so that a later step can count its rows.

Describe every operation clearly in English. Phrases such as the following are supported:

  • use table, select, or filter rows where
  • group rows by, compute count of, compute sum of, or compute average of
  • keep groups where
  • name result and then compute count of its rows

Name every table and column exactly as shown above. Include every expression, comparison, value, grouping column, calculation input, intermediate-result name, and output alias needed by your steps. Code-like shorthand such as groupby or df[...] is not accepted as English analysis-plan wording.
