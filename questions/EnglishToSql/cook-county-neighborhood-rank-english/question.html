Each row of the dataset represents one property sale.

Note: For this question, a valid sale has modeling_group = 'SF', sale_price >= 10000, and building_sqft > 0.

(a) Neighborhood price leaderboard

For each year from 2016 through 2019, find the three neighborhoods with the highest average sale price per building square foot. Only use valid sales that have a garage.

Use the following definitions:

  • For one sale, price_per_sqft = sale_price * 1.0 / building_sqft.
  • A neighborhood qualifies in a given year only if it has at least 10 qualifying sales in that year.
  • sale_count is the number of qualifying sales for a neighborhood in a given year.
  • avg_price_per_sqft is the average price_per_sqft for a neighborhood in a given year, rounded to two decimal places.

Rank qualifying neighborhoods separately within each year by avg_price_per_sqft from highest to lowest. Break ties by neighborhood_code from lowest to highest, and keep ranks 1 through 3.

The final table must contain sale_year, neighborhood_code, sale_count, avg_price_per_sqft, and rank_in_year.

(b) Busiest years by property class

For each property_class, find the two years from 2013 through 2019 with the most valid sales that have central air.

Use the following definitions:

  • A property class qualifies in a given year only if it has at least 25 qualifying sales in that year.
  • sale_count is the number of qualifying sales for a property class in a given year.
  • avg_sale_price is the average sale_price for a property class in a given year, rounded to two decimal places.

Rank qualifying years separately within each property_class by sale_count from highest to lowest. Break ties by sale_year from lowest to highest, and keep ranks 1 and 2.

The final table must contain property_class, sale_year, sale_count, avg_sale_price, and rank_in_class.
